# M-Gas Website – Furahia Upishi Wako

Professional single-page website for **M-Gas** (Pay-As-You-Cook LPG service in Kenya).

## Quick start

1. Clone or download this repository
2. Open `index.html` in any modern browser  
   **or** host the whole folder on GitHub Pages / Netlify / Vercel

```bash
# Example – GitHub Pages
# 1. Create a new repo on GitHub
# 2. Push these files
git init
git add .
git commit -m "M-Gas website – picture-rich landing page"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/mgas-website.git
git push -u origin main
```

Then enable **GitHub Pages** (Settings → Pages → Deploy from main branch).
